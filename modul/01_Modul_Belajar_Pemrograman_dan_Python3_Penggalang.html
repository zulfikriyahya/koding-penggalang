Bab 1. Cara Berpikir Sebelum Menulis Kode

Sebelum mengetik di komputer, seorang pemrogram selalu memecahkan soal di atas kertas atau di kepala menggunakan 4 langkah Berpikir Komputasional (sesuai Kurikulum Informatika SMP/MTs dan Tantangan Bebras Penggalang):

  1. Dekomposisi (Memecah Masalah): Pecah soal yang panjang menjadi tugas-tugas kecil. Contoh: saat menyiapkan perkemahan, kita pecah menjadi: hitung jumlah tenda, hitung kebutuhan air, lalu cek stok cukup atau kurang.
  2. Pengenalan Pola (Mencari Aturan yang Berulang): Amati hal yang selalu sama. Contoh: pada Sandi Geser, setiap huruf selalu bergeser dengan jarak langkah yang sama.
  3. Abstraksi (Mengambil Inti Soal): Fokus pada data dan rumus yang diminta soal, abaikan hiasan cerita. Jika soal bercerita tentang "Regu Elang berkemah di kaki gunung membawa 17 peserta", inti datanya cukup angka 17.
  4. Algoritma (Menyusun Langkah Berurutan): Tulis urutan kerja komputer dari awal sampai akhir: (1) Baca Input → (2) Hitung / Proses → (3) Cetak Output.

Bab 2. Mengenal Program Python 3 & Aturan Lomba

Program adalah kumpulan perintah tertulis yang dijalankan komputer secara berurutan dari baris paling atas ke bawah. Bahasa yang dipakai dalam lomba adalah Python 3, yang disimpan dalam file berakhiran .py (contoh: soal1_ELANG.py).

Untuk menjalankan file Python 3 di komputer (Windows, Linux, maupun macOS), kamu bisa memakai editor apa saja yang diperbolehkan panitia (IDLE, VS Code, Sublime Text, atau editor standar lain), atau lewat terminal/command prompt dengan mengetik:

python3 soal1_ELANG.py
Aturan Teknis Wajib pada Juknis Lomba Coding Python:
1. Fungsi input() ditulis kosong tanpa teks di dalam kurung. Tulis nama = input(), jangan tulis nama = input("Masukkan nama: "). Jika ada teks di dalam kurung, teks itu akan ikut tercetak ke layar sehingga jawaban dianggap tidak sesuai format oleh penilai.
2. Keluaran (print()) harus sama persis dengan contoh pada soal, termasuk huruf besar/kecil, spasi, tanda titik dua, dan jumlah angka di belakang koma.
3. Nama file jawaban mengikuti format panitia: soalN_NAMATIM.py (1 file untuk 1 soal).
4. Dilarang mengakses internet selain Google Form pengumpulan, dilarang menggunakan AI (ChatGPT, Copilot, dan sejenisnya), HP, atau menyalin kode. Boleh membuka catatan buku atau PDF materi sintaks.

Bab 4. Membaca Input & Mencetak Output dengan Tepat

Menurut dokumentasi resmi Python 3, fungsi input() selalu menghasilkan teks (str) meskipun kamu mengetik angka. Karena itu, jika input berupa angka yang akan dihitung, ubah dulu memakai int() atau float().

Pola Input yang Paling Sering Dipakai

# 1. Membaca 1 baris teks
regu = input().strip()

# 2. Membaca 1 bilangan bulat
n = int(input())

# 3. Membaca 1 bilangan desimal
stok = float(input())

# 4. Membaca 2 angka di 1 baris (dipisah spasi)
# Contoh input: 17 6
p, k = map(int, input().split())

# 5. Membaca daftar angka di 1 baris
# Contoh input: 80 90 85 95
nilai = list(map(int, input().split()))

Pola Mencetak Output (print & f-string)

regu = "ELANG"
nilai = 86.5
jam = 7
menit = 5

# f-string: letakkan f sebelum tanda kutip
print(f"Regu {regu} memperoleh {nilai:.2f}")
print(f"Waktu: {jam:02d}:{menit:02d}")

# Menggabungkan list teks dengan 1 spasi
kata = ["Pramuka", "Penggalang", "Jaya"]
print(" ".join(kata))
Output: Regu ELANG memperoleh 86.50 Waktu: 07:05 Pramuka Penggalang Jaya

Bab 6. Percabangan (if, elif, else)

Percabangan dipakai ketika program harus memilih tindakan berbeda berdasarkan kondisi tertentu. Di Python, blok kode di dalam if ditandai dengan tanda titik dua (:) dan jarak masuk ke dalam (indentasi) 4 spasi.

sudut = 135

if sudut == 0:
    arah = "Utara"
elif sudut == 90:
    arah = "Timur"
elif sudut == 135:
    arah = "Tenggara"
else:
    arah = "Arah lainnya"

print(arah)
Output: Tenggara
Catatan Penting tentang elif: Komputer memeriksa kondisi dari atas ke bawah. Begitu ada satu kondisi yang bernilai benar (True), blok di bawahnya dijalankan lalu sisanya dilewati. Jadi urutan kondisi rentang angka (misalnya dari kecil ke besar) harus rapi.

Bab 7. Perulangan (for & while)

Jika kamu harus mengulang pekerjaan yang sama berkali-kali—misalnya membaca data 10 regu atau memeriksa setiap huruf dalam kalimat sandi—gunakan perulangan.

Perulangan for dengan range()

# range(4) menghasilkan 0, 1, 2, 3
for i in range(4):
    print(f"Pos ke-{i + 1}")

# Pola akumulator (menjumlahkan nilai)
skor_pos = [80, 90, 85]
total = 0
for s in skor_pos:
    total = total + s
print(f"Total: {total}")
Output: Pos ke-1 Pos ke-2 Pos ke-3 Pos ke-4 Total: 255

Perulangan while, break & continue

# while terus berulang selama kondisi True
sisa = 3
while sisa > 0:
    print(f"Hitung mundur: {sisa}")
    sisa = sisa - 1

# break    -> hentikan loop seketika
# continue -> lompati sisa putaran ini
Output: Hitung mundur: 3 Hitung mundur: 2 Hitung mundur: 1

Bab 8. Mengolah Teks (str) untuk Sandi Pramuka

Dalam SKU Penggalang (SK Kwarnas No. 198/2011), sandi dan isyarat adalah materi penting. Di Python, sebuah teks (str) dapat diperiksa huruf demi huruf memakai for huruf in teks:.

PerintahContohHasil
.upper() / .lower()"Elang".upper()"ELANG"
.strip()" halo ".strip()"halo"
.split()"A B C".split()["A", "B", "C"]
.replace(a, b)"1-2-3".replace("-", " ")"1 2 3"
[::-1] (membalik teks)"PRAMUKA"[::-1]"AKUMARP"
ord(huruf)ord("A")65 (kode angka ASCII huruf A)
chr(angka)chr(65)"A" (ubah kode ASCII jadi huruf)

Contoh Nyata: Menerjemahkan Sandi AZ (A↔Z, B↔Y, dst.)

sandi = "KIZNFPZ"
hasil = ""
for huruf in sandi.upper():
    if "A" <= huruf <= "Z":
        # Jarak dari A dibalik terhadap Z
        asli = chr(ord("Z") - (ord(huruf) - ord("A")))
        hasil = hasil + asli
    else:
        hasil = hasil + huruf
print(hasil)
Output: PRAMUKA

Bab 9. Menyimpan Banyak Data (list & dict) & Mengurutkan

1. list (Daftar Berurut): Menyimpan banyak data di dalam kurung siku [...]. Nomor urut (indeks) di Python selalu dimulai dari 0!

regu = ["Elang", "Garuda", "Kancil"]
print(regu[0])       # Elang (elemen pertama)
print(regu[-1])      # Kancil (elemen terakhir)
regu.append("Mawar") # Menambah elemen di belakang
print(len(regu))     # 4
Output: Elang Kancil 4

2. dict (Kamus Pasangan Kunci → Nilai): Sangat berguna untuk Sandi Morse atau menyimpan nilai per regu.

morse = {".-": "A", "-...": "B", "-.-.": "C", "---": "O", "...": "S"}
pesan = "... --- ..."
terjemahan = ""
for kode in pesan.split():
    terjemahan = terjemahan + morse.get(kode, "?")
print(terjemahan)
Output: SOS

3. Mengurutkan Data (sort): Sering dipakai pada soal klasemen/peringkat regu.

# Format: (nama_regu, total_nilai, nilai_pionering)
klasemen = [
    ("GARUDA", 84, 90),
    ("ELANG", 86, 80),
    ("RAJAWALI", 84, 90),
    ("KANCIL", 90, 90),
]
# Tanda minus (-) artinya urut dari TERBESAR ke terkecil; tanpa minus = A ke Z
klasemen.sort(key=lambda r: (-r[1], -r[2], r[0]))
for peringkat, r in enumerate(klasemen, start=1):
    print(f"{peringkat}. {r[0]} - {r[1]}")
Output: 1. KANCIL - 90 2. ELANG - 86 3. GARUDA - 84 4. RAJAWALI - 84

Bab 10. Fungsi (def) & Kamus Error Python untuk Pemula

Fungsi adalah blok kode yang diberi nama agar bisa dipanggil berulang kali dan membuat program rapi, mudah dibaca, serta mudah dicek oleh rekan setim.

def hitung_back_azimuth(azimuth):
    if azimuth < 180:
        return azimuth + 180
    return azimuth - 180

print(hitung_back_azimuth(45))
print(hitung_back_azimuth(270))
Output: 225 90
